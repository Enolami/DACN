# Frontend Application

This is the frontend application built with React and TypeScript.

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Running the Application

```bash
npm start
```

The application will open at [http://localhost:3000](http://localhost:3000)

### Building for Production

```bash
npm run build
```

## Project Structure

```
frontend/
├── components/      # Reusable React components
├── guidelines/      # Project guidelines and best practices
├── styles/          # Global styles and CSS files
├── App.tsx          # Main application component
├── Attributions.md  # Attributions and credits
└── package.json     # Project dependencies
```

## Development

- Follow the guidelines in the `guidelines/` directory
- Use TypeScript for type safety
- Keep components in the `components/` directory
- Global styles go in the `styles/` directory
