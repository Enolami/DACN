# Styling Guidelines

## CSS Architecture

- Use CSS modules for component-specific styles
- Global styles should be in the `styles` directory
- Follow a consistent color palette

## Responsive Design

- Mobile-first approach
- Breakpoints: 768px, 1024px, 1440px
- Test on multiple devices

## Color Scheme

- Primary: #007bff
- Secondary: #6c757d
- Success: #28a745
- Danger: #dc3545
- Warning: #ffc107
